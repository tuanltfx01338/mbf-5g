Cách lấy Google Maps API key
  1. Vào Google Cloud, mục Credentials và tạo API key.
  2. Bật 2 dịch vụ: Maps JavaScript API và Geocoding API.
  3. Giới hạn key theo website (HTTP referrer) và chỉ cho 2 API trên.

Key chỉ lưu trong trình duyệt này, không nằm trong file. Hãy đọc điều khoản Google Maps Platform về lãnh thổ bị hạn chế trước khi dùng.
